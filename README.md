# Bonfire.Data.Time

Database models for times and schedules in the [Bonfire](https://bonfirenetworks.org/) ecosystem.

- `Bonfire.Data.Time.TimeSpan`: a mixin for when something begins, shared by any object that has a time (an event, or a ValueFlows intent, commitment or economic event).
